# Annesha Chatterjee, PhD

Cancer cell biologist based in Eindhoven, the Netherlands. My PhD (IIT Dharwad, Biosciences and Bioengineering) combined analysis of patient-cohort and sequencing data with laboratory work on lung-cancer signalling, mitochondrial stress and drug response. I also peer-review and edit research manuscripts.

**Work:** biology, cancer biology, survival analysis, transcriptomics, quantitative problems in R and Python, and checking scientific and statistical reasoning.

## Code

Code from my doctoral research (2020–2025), collected and documented here in 2026.

| Repository | What it shows |
|---|---|
| [pan-cancer-expression-screen](https://github.com/Annesha-1312/pan-cancer-expression-screen) | My 2020 R script for a tumour-versus-normal screen across TCGA tumour types, refactored, ported to Python and tested against the original logic |
| [rnaseq-workflow](https://github.com/Annesha-1312/rnaseq-workflow) | The paired-end RNA-seq workflow I ran for an unpublished overexpression experiment from my thesis (FastQC, Trim Galore, STAR, featureCounts, DESeq2, clusterProfiler), code only |
| [biology-solution-review](https://github.com/Annesha-1312/biology-solution-review) | Four biology problems (enzyme kinetics, antibiotic time-kill, qPCR, survival) solved in Python, each with an illustrative flawed answer checked line by line, every flaw named and covered by tests |
| [biology-quant-notebooks](https://github.com/Annesha-1312/biology-quant-notebooks) | Worked problems in Python: dose-response IC50 fitting, Kaplan-Meier and log-rank tests from scratch, multiple-testing correction, growth kinetics with SymPy, and a review of a flawed AI-style answer |

**Tools:** R (tidyverse, ggplot2, DESeq2, survival, ComplexHeatmap), Python (pandas, NumPy, SciPy, SymPy, matplotlib, Jupyter), Linux command line, Git. I write code with AI coding agents (Claude Code, GitHub Copilot, Cursor) and check every result before relying on it.
